# M0 Environment setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the M0 milestone of the AB-620 HR Assistant study project: repo skeleton, mock data, a Power Platform developer environment, the Copilot Studio trial, SharePoint policy documents, the Dataverse employee table, and the first version of the coverage table.

**Architecture:** The repo is a learning log, not product code. Tasks 1–2 are files and scripts that can run automatically on this machine; Tasks 3–6 are sign-ups and configuration the user does by hand in the browser, each step with a verifiable checkpoint; Task 7 wraps up with notes and a commit. M1–M7 each get their own plan written when they start, so that Copilot Studio UI changes don't leave steps out of date.

**Tech Stack:** Git, Markdown, Python 3.13 + python-docx (converts the Markdown policy documents into .docx for SharePoint indexing), Power Apps Developer Plan, Copilot Studio trial, SharePoint Online, Dataverse.

**Spec:** `docs/superpowers/specs/2026-09-13-ab-620-hr-assistant-design.md`

## Global Constraints

- Notes in Chinese prose; English terms left untranslated on first appearance.
- Cost: M0 uses only free and trial offerings; no Azure.
- If any single step is stuck for more than 1 hour, stop, record it in `milestones/M0-environment/break-and-fix.md`, and move on to the next step.
- Mock data: 20 employee rows, 4 policy documents, company name Contoso.
- Environment name fixed as `HR-Dev`; agent name fixed as `HR Assistant`; SharePoint site name fixed as `HR Policies`.
- Commit at the end of every Task; commit messages in English.

`src/tools/md_to_docx.py`:

```python
"""Convert data/policies/*.md into .docx files for SharePoint upload.

Handles only the Markdown subset used in the policy docs: '# ', '## ' headings
and plain paragraphs. Blank lines separate paragraphs.
"""
import sys
from pathlib import Path

from docx import Document

SRC = Path(__file__).resolve().parents[2] / "data" / "policies"
OUT = SRC / "docx"


def convert(md_path: Path) -> Path:
    doc = Document()
    paragraph: list[str] = []

    def flush() -> None:
        if paragraph:
            doc.add_paragraph(" ".join(paragraph))
            paragraph.clear()

    for line in md_path.read_text(encoding="utf-8").splitlines():
        if line.startswith("# "):
            flush()
            doc.add_heading(line[2:].strip(), level=1)
        elif line.startswith("## "):
            flush()
            doc.add_heading(line[3:].strip(), level=2)
        elif line.strip() == "":
            flush()
        else:
            paragraph.append(line.strip())
    flush()

    OUT.mkdir(exist_ok=True)
    out_path = OUT / (md_path.stem + ".docx")
    doc.save(out_path)
    return out_path


def main() -> int:
    md_files = sorted(SRC.glob("*.md"))
    if not md_files:
        print("no markdown files found in", SRC, file=sys.stderr)
        return 1
    for md in md_files:
        print("wrote", convert(md))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
